# 긴급 AA 누적 복구

적용 대상은 긴급(긴조) 서식입니다. 인앱·귀책에는 이 기능을 넣지 않습니다.

기존 ‘즉시 새로고침’ 스크립트를 이 Gist의 최신 **투입률 관리 긴급 서식 즉시 새로고침 패치** 코드로 전체 교체 → 저장 → 한 번 실행합니다. 기존 버튼과 현재 파일을 그대로 사용합니다. XLSX 안 초기 설치 코드를 다시 실행하지 마세요.

| 실행 상황 | 기록 |
|---|---|
| 상태출력 A1에 원문 붙여넣고 버튼 실행 | 현재 파일에서 계산된 구간을 AA6:AA29에 저장합니다. |
| 같은 구간에서 다시 실행 | 같은 줄을 최종 결과로 갱신합니다. 정상 출근과 OT 미출근 문제가 모두 없어야 ‘결점 없음’입니다. |
| 다음 구간 | 이전 구간 마지막 결과를 유지하고 다음 줄에 저장합니다. 실행하지 않은 구간은 채우지 않습니다. |
| 자정 | 같은 운영일로 24~25부터 28~29까지 이어갑니다. |
| 다음 오전 5시 | 첫 실행에서 이전 하루 AA6:AA29를 초기화하고 05~06부터 새로 작성합니다. |

AA3 공유 제목, AA33 데일리 결점과 AA34 아래 예정 이탈 목록도 복구합니다. 이전 순서형 기록은 같은 운영일이면 시간별 위치로 옮깁니다. 기록은 24칸만 사용하여 아래 명단과 겹치지 않습니다. 첫 복구 시 AA34:AA2003의 기존 출력은 예정 이탈 수식으로 교체합니다. A1, D5, H5:I5:J5, 교육 AH10:AH35와 예외 L34:L43은 변경하지 않습니다.

기준 시각은 수식설정 B3이며 오전 5시를 기준으로 연도를 포함한 운영일을 저장합니다. 원문이 비었거나 계산 오류가 있으면 기존 기록을 유지하고 출력 창에 이유를 남깁니다.

자동 편집 이벤트나 자동 시간 타이머는 아닙니다. **원문 붙여넣기 후 버튼을 누를 때 기록**합니다. 외부 원본 새로고침은 비동기 요청이므로 현재 화면의 계산 결과를 저장합니다. 원본 수정이 반영된 후 최종 확인하려면 같은 버튼을 다시 누르세요.

모의 계산·누적·오전 5시 전환·오류 보존을 검사했습니다. 실제 회사 Excel 웹과 공동 편집 환경은 미검증입니다.
