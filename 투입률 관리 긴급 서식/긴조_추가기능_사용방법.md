# 긴조 자동 기록 추가 기능

[설치 파일 다운로드와 순서 안내](https://ginjo-auto-record-20261114-yek.yek5623.chatgpt.site/) · [XML 바로 받기](https://ginjo-auto-record-20261114-yek.yek5623.chatgpt.site/manifest.xml)

현재 긴조 수식 파일을 그대로 사용합니다. 인앱·귀책에는 적용하지 않습니다. 이 추가 기능은 Office Script를 자동 실행하는 방식이 아니라 Excel의 A1 변경 이벤트를 직접 감지합니다.

## 설치

1. `긴조_추가기능.xml`을 내려받습니다. 추가 기능의 코드 주소가 공개되어 있어야 Excel에서 불러올 수 있습니다.
2. 긴조 파일을 Excel 웹에서 열고 홈 → 추가 기능 → 추가 설정 → 내 추가 기능 업로드에서 XML을 선택합니다.
3. 열린 패널에서 처음 한 번 `자동 기록 켜기`를 누릅니다. 상태가 `켜짐`인지 확인합니다.
4. 이후 상태출력 A1에 원문을 붙여넣습니다. 매번 스크립트 버튼을 누르지 않습니다.

기존 새로고침 버튼도 계속 사용할 경우, 이 Gist의 최신 `투입률 관리 긴급 서식 즉시 새로고침 패치`로 스크립트를 한 번 교체해 두면 추가 기능이 켜진 동안 수동 AA 중복 기록을 생략합니다.

기존 XLSX를 다시 만들거나 초기 설치 스크립트를 다시 실행하지 않습니다. 수식설정 B2에 수기로 고정한 기준 시각이 있다면 먼저 비워 주세요. 셀 변경 이벤트는 이 추가 기능이 작동 중인 화면의 직접 변경만 처리합니다. 다른 공동 편집자의 원격 변경은 중복 기록을 막기 위해 처리하지 않습니다.

## 동작

| 변경 | 결과 |
|---|---|
| A1에 새 원문 입력 | 입력을 감지한 한국 시각을 D5에 값으로 저장하고 계산 완료 후 AA를 기록합니다. |
| A1 이외의 칸 수정 | D5와 AA는 추가 기능이 변경하지 않습니다. |
| 같은 시간대에 다시 입력 | 해당 구간 한 줄을 최신 결과로 갱신합니다. 정상 출근·OT 미출근 문제가 모두 없어야 ‘결점 없음’입니다. |
| 다음 시간대 입력 | 이전 구간의 마지막 결과를 남기고 다음 구간을 기록합니다. 입력하지 않은 구간은 빈칸입니다. |
| 자정 이후 | 같은 운영일의 24~25부터 28~29까지 이어갑니다. |
| 오전 5시 이후 첫 입력 | 이전 운영일 기록을 초기화하고 05~06부터 새로 시작합니다. |
| A1 비우기 | D5는 비우고 이전 AA 기록은 유지합니다. |
| 해석·계산 오류 | 작성 시각은 기록하지만 AA의 이전 결과는 유지하고 패널에 이유를 표시합니다. |

AA3 공유 제목, AA33 데일리 결점과 AA34 아래 예정 이탈 목록도 사용합니다. H5:I5:J5, 수기 교육 AH10:AH35와 예외 L34:L43은 변경하지 않습니다. 처음 활성화하거나 파일을 다시 열었다는 이유만으로 기존 A1을 새 입력으로 간주하지 않습니다. **다음 실제 A1 변경부터 기록합니다.**

빠르게 연속해서 붙여넣으면 오래된 계산은 취소하고 최신 입력을 처리합니다. 계산 중 시간대가 바뀌어 입력 시각과 판정 시간대가 다르면 AA 기록을 유지하며 안내를 표시합니다. 같은 내용을 다시 붙여도 Excel이 변경 이벤트를 발생시키지 않는 환경에서는 새 입력 시각을 감지할 수 없습니다.

## 재열기와 일시 중지

공유 런타임과 자동 시작 설정을 사용해 같은 문서를 다시 열면 변경 이벤트를 재등록합니다. 첫 활성화는 직접 해야 합니다. 브라우저·계정을 바꾸거나 캐시를 삭제하면 추가 기능을 다시 설치해야 할 수 있습니다. 파일을 닫은 동안에는 실행하지 않습니다. 런타임이나 회사 정책이 자동 시작을 막으면 패널에서 상태를 확인해야 합니다.

추가 기능을 멈추려면 패널에서 `끄기`를 누릅니다. 기존 새로고침 스크립트도 최신판을 쓰면, 추가 기능이 켜진 동안 수동 AA 중복 기록을 생략합니다. 원본 데일리 링크 자동 갱신과 월별 연결 설정은 기존 방식을 유지합니다. 외부 원본이 서버에서 최신으로 갱신되었는지 이 기능이 보장하지는 않습니다.

## 처음 확인할 것

복사본에서 A1을 붙여넣고 D5와 AA에 기록되는지 확인합니다. 다른 칸을 바꿔도 D5가 그대로인지, 같은 시간대 재입력은 같은 AA 줄을 갱신하는지 확인합니다. 파일을 닫았다 열었을 때 패널 상태가 `켜짐`으로 돌아오는지도 확인합니다.

설치 XML은 Microsoft 공식 manifest 검사를 통과했습니다. A1 감지·D5 고정·시간대 누적·오전 5시 전환·빠른 연속 입력·오류 보존·잘못된 파일 차단·활성화 실패 복구를 모의 API에서 검사했습니다. **실제 회사 Excel 계정의 설치와 실행은 아직 확인하지 못했습니다.**

추가 기능은 문서를 읽고 쓰기 위한 `ReadWriteDocument` 권한을 요청합니다. A1 원문과 직원 명단을 별도 서버로 보내는 통신 코드는 넣지 않았으며 기록은 통합문서에 저장합니다. 웹 주소는 HTML·JavaScript·아이콘을 제공하는 용도입니다.
