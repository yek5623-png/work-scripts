긴조 자동 기록 · Excel 웹

붙여넣기 한 번으로
작성 시각과 시간대 기록까지.

현재 사용하는 긴조 수식 파일에 추가 기능을 연결합니다. 인원·명단 계산은 기존 수식이 맡고, 이 추가 기능은 A1 변경만 감지해 D5와 AA를 기록합니다.

추가 기능 설치 파일 받기
1. 파일 열기기존 긴조 파일을 Excel 웹에서 엽니다. 시트 복사나 초기 설치를 다시 하지 않습니다.
2. 추가 기능홈 → 추가 기능 → 추가 설정 → 내 추가 기능 업로드에서 위 XML 파일을 선택합니다.
3. 처음 한 번긴조 자동 기록 패널에서 자동 기록 켜기를 누르고, 상태가 ‘켜짐’인지 확인합니다.
4. 이후 사용상태출력 A1에 원문을 붙여넣습니다. 매번 스크립트 버튼을 누르지 않습니다.
먼저 복사본에서 확인하세요.

A1을 붙여넣은 뒤 D5와 AA가 기록되는지 확인하고, 다른 셀을 수정했을 때 D5가 그대로인지 확인합니다. 같은 시간대 재입력은 같은 줄을 갱신합니다.

기록 규칙

문제가 모두 해소되면 ‘결점 없음’으로 저장합니다. 자정에는 기록을 유지하고 24~25부터 28~29까지 이어갑니다. 다음 운영일 오전 5시의 첫 A1 입력은 05~06부터 새로 시작합니다. 입력하지 않은 시간대는 채우지 않습니다.

사용 조건

파일이 열려 있고 이 추가 기능이 작동해야 합니다. 현재 화면에서 직접 바꾼 A1만 기록하며, 다른 공동 편집자의 변경은 처리하지 않습니다. 설치는 브라우저에 저장되므로 브라우저나 계정을 바꾸거나 캐시를 삭제하면 다시 설치해야 할 수 있습니다.

기존 수식설정 B2에 수기 기준 시각이 있으면 먼저 비워 주세요. 계산 오류가 있으면 기존 AA 기록을 남기고 패널에 이유를 표시합니다. 일시 중지하려면 패널에서 ‘끄기’를 누릅니다.

자료 처리

이 주소는 추가 기능 코드만 제공합니다. A1 원문과 직원 명단은 Excel 안에서 읽고 기록하며, 별도 서버나 데이터베이스로 보내지 않습니다. 회사의 추가 기능 정책이 설치를 제한할 수 있습니다.
