긴조웹 화면 수정 적용

현재 잘 되는 Power Automate와 데일리.json은 그대로 유지합니다.

1. 새 긴조웹_템플릿.txt를 다운로드합니다.
2. SharePoint 긴조웹 폴더의 같은 이름 파일에 덮어씁니다.
3. 기존 Power Automate가 다음 주기에 실행될 때까지 기다리거나, 기존 흐름을 한 번 수동 실행합니다.
4. 팀장님들이 쓰는 기존 HTML 링크를 다시 엽니다.

HTML 자체를 빈 초기 파일로 교체할 필요는 없습니다. 흐름이 새 템플릿에 실제 데이터를 넣어 기존 HTML을 갱신합니다.
자리표시자와 데이터 형식은 유지했으므로 현재 성공하는 '작성' 식과 파일 업데이트 단계는 변경하지 마세요.

반영된 화면 수정
- 연결 상태 배지와 웹 계산형/연결 설정 안내줄을 화면 맨 아래로 이동
- 상태 기준 옆에 마지막 데일리 생성/내보내기 시각 표시 (HTML을 연 시각이 아닌 원본 capturedAt)
- 웹에서 계산 버튼을 상태 원문 붙여넣기 버튼 왼쪽으로 이동
- 왼쪽 아래 GPT 없이 실행 문구 제거
- 샘플 보기, 결과 내보내기 버튼 제거

아직 구현되지 않은 요청
입력과 결과의 실시간 공동 저장은 이번 HTML 화면 수정에 포함되지 않았습니다.
현재는 계산 결과를 서버로 저장하는 연결이 없고, Power Automate가 주기적으로 HTML을 생성합니다.
HTML 내부의 자바스크립트 변수를 바꿔도 SharePoint의 원본 파일이 바뀌지는 않습니다.
사용자가 확인한 origin null / about:srcdoc 미리보기는 브라우저 저장소도 제한할 수 있습니다.
개인 PC 저장을 추가해도 다른 팀장님의 화면과는 공유되지 않습니다.
자동화와 별도 앱 설치를 더 하지 않고 엑셀처럼 실시간으로 공동 편집·저장하려면 기존 공유 Excel을 사용하는 방식을 권합니다.
