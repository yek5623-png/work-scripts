# 투입률 관리 귀책 서식 K열·D3 업데이트

기존 파일의 자동화 → 기존 즉시 새로고침 스크립트 편집 → **투입률 관리 귀책 서식 K열 D3 업데이트 패치** 전체 코드로 교체 → 저장 → 한 번 실행하세요. 이후 기존 버튼을 그대로 사용합니다. 처음 한번 설치는 다시 실행하지 않습니다.

- 데일리 K6:K180를 선택 날짜 원본의 같은 범위로 연결합니다. 빈칸·0을 구분하며 날짜/월 변경도 유지합니다.
- 상태출력 E5는 현재 시간대(BA열)의 AY열 목표 인원입니다. D3에 해당 인원 기준 최소~최대 투입률을 표시합니다. 귀책 전용 인원별 기준표를 유지합니다.
- AY가 빈칸/0/오류이면 확인 문구를 표시합니다. 05시 이전은 24~28시 기준을 유지합니다.
- H5:I5:J5, D5, 수기 교육 및 긴급 AA 누적은 기존 동작을 유지합니다.
- 외부 링크 갱신은 비동기입니다. 원본 접근·신뢰가 필요하며 서버 반영까지 지연될 수 있습니다.
