인앱·귀책 투입률 — 파워 오토메이트 A to Z 설정 가이드
처음 해보는 분도 따라 할 수 있게 한 단계씩 적었습니다. 순서대로 하나씩 하세요. 막히면 그 단계의 "확인" 항목을 보고, 안 되면 화면 캡처를 보내주세요.
0. 전체 그림 (먼저 읽기)
자동으로 이렇게 돌아갑니다.
1.  엑셀 스크립트가 데일리 엑셀을 읽어서 글자(JSON)로 만듭니다. (인앱용, 귀책용 2개)
2.  플로우 1·2가 3분마다 그 글자를 SharePoint의 데일리.json 파일에 저장합니다.
3.  플로우 3이 3분마다 템플릿 + 인앱 데이터 + 귀책 데이터를 합쳐서 대시보드 HTML 한 개를 만듭니다.
4.  팀장님들은 그 HTML 한 개를 열면 사이드바에 인앱 / 귀책 두 묶음이 보입니다.
이름
역할

인앱_데일리_읽기, 귀책_데일리_읽기
엑셀에서 데이터를 읽는 스크립트 2개

플로우 1 (인앱), 플로우 2 (귀책)
스크립트를 3분마다 실행해 JSON 저장

플로우 3 (화면 만들기)
템플릿과 JSON 2개를 합쳐 HTML 저장

하루 호출 수: 플로우 1과 2가 각각 하루 480번 스크립트를 실행합니다. 합 960번이고, 한 계정의 한도는 하루 1,600번이라 한 계정으로 충분합니다. (한도는 한국 시간 오전 9시에 초기화됩니다.)
1. 준비물 체크
• 회사 Microsoft 365 계정으로 로그인한 Edge 또는 Chrome
• 인앱 데일리 엑셀, 귀책 데일리 엑셀 (둘 다 OneDrive 또는 SharePoint에 저장된 파일이어야 합니다. 내 PC에만 있으면 안 됩니다.)
• SharePoint 사이트 하나 (파일을 올릴 수 있는 권한 필요)
• 이 저장소의 파일 3개: 인앱귀책웹_템플릿.txt, 인앱_데일리_읽기_스크립트.ts, 귀책_데일리_읽기_스크립트.ts
확인: 엑셀 파일을 브라우저에서 열었을 때 위쪽 메뉴에 자동화(Automate) 탭이 보이면 됩니다. 없으면 회사 관리자에게 "Office Scripts 사용 허용"을 요청하세요.
2. SharePoint 사이트 데이터 만들기
2-1. 폴더 3개 만들기
1.  SharePoint 사이트 → 문서(Documents) 로 들어갑니다.
2.  새로 만들기 → 폴더 로 아래 3개를 만듭니다.
    ◦ 인앱웹
    ◦ 귀책웹
    ◦ 인앱귀책웹
2-2. 파일 올리기
1.  인앱귀책웹 폴더에 인앱귀책웹_템플릿.txt 를 업로드합니다. (이름을 바꾸지 마세요.)
2.  인앱웹 폴더와 귀책웹 폴더에는 아래 3-5의 스크립트 첫 실행 뒤에 데일리.json 이 생깁니다. 지금은 비워 둡니다. 다만 플로우 3의 "파일 가져오기"를 설정하려면 파일이 먼저 있어야 하므로, 메모장으로 {} 라고 적은 데일리.json 을 만들어 두 폴더에 각각 올려 두세요.
2-3. 공유 목록 2개 만들기 (이슈명단·수기 입력 공유 저장용)
입력값을 다른 팀장님과 같이 보려면 필요합니다. 처음에는 건너뛰고 나중에 추가해도 됩니다.
1.  사이트 홈 → 새로 만들기 → 목록 → 빈 목록
2.  이름 인앱 공유, 만들기
3.  열 추가 → 여러 줄 텍스트, 이름은 정확히 Payload (대소문자 맞게)
4.  같은 방법으로 귀책 공유 목록을 만듭니다.
5.  각 목록에 항목을 1개씩 만듭니다. (제목은 아무거나, Payload는 비워 둠). 항목 번호(ID)가 1인지 확인하세요.
확인: 폴더 3개, 템플릿 1개, 데일리.json 2개(지금은 {}), (선택) 목록 2개가 있으면 됩니다.
3. 엑셀 스크립트 2개 만들기
인앱 데일리 엑셀과 귀책 데일리 엑셀에 각각 합니다.
3-1. 인앱 엑셀
1.  인앱 데일리 엑셀을 브라우저(Excel 웹) 로 엽니다.
2.  위쪽 자동화 탭 → 새 스크립트
3.  오른쪽에 코드 창이 열립니다. 기본 코드를 전부 지웁니다. (Ctrl+A → Delete)
4.  인앱_데일리_읽기_스크립트.ts 내용을 전부 복사해서 붙여넣습니다.
5.  코드 맨 위쪽 시트머리말 을 확인합니다. 엑셀 시트 이름이 인앱전담 11(23) 처럼 되어 있으면 "인앱전담" 그대로 둡니다. 시트 이름이 예전처럼 긴급 11(23) 이면 그대로 둬도 자동으로 찾습니다.
6.  저장하고, 이름을 인앱_데일리_읽기 로 바꿉니다.
7.  실행 버튼을 눌러 한 번 시험합니다.
확인: 아래 "출력" 칸에 {"type":"ginjo-daily-blocks", ... 로 시작하는 긴 글자가 나오면 성공입니다. "원본에 ○○ 시트가 없습니다"가 나오면 오늘 날짜 시트가 없거나 시트머리말 이 시트 이름과 다른 것입니다.
3-2. 귀책 엑셀
같은 방법으로 귀책 엑셀에서 귀책_데일리_읽기_스크립트.ts 를 붙여넣고 이름을 귀책_데일리_읽기 로 저장하고 실행해 봅니다.
4. 플로우 1 만들기 — 인앱 데이터 저장
1.  브라우저에서 make.powerautomate.com 을 엽니다. (회사 계정 로그인)
2.  왼쪽 만들기 → 예약된 클라우드 흐름
3.  이름 인앱_데일리_읽기 / 시작은 지금 / 반복 간격 3 / 분 → 만들기
4.  위쪽 트리거(반복)를 눌러 펼치고 고급 옵션 보기 → 표준 시간대: (UTC+09:00) 서울 선택
5.  + 새 단계 → "스크립트 실행" 검색 → Excel Online (Business) 의 스크립트 실행
    ◦ 위치: OneDrive for Business 또는 해당 SharePoint 사이트
    ◦ 문서 라이브러리: 엑셀이 있는 곳
    ◦ 파일: 인앱 데일리 엑셀 (이번 달 파일)
    ◦ 스크립트: 인앱_데일리_읽기
    ◦ 아래 "고급 매개 변수 표시"에서 기준시각, 모드, 다음달예상 칸에는 모두 - (하이픈 한 글자)를 입력합니다. 비워 두는 뜻입니다.
    ◦ 이 단계의 이름(… 점 세 개 → 이름 바꾸기)을 Run_daily 로 바꿉니다.
6.  + 새 단계 → "파일 업데이트" → SharePoint 의 파일 업데이트
    ◦ 사이트 주소: 위에서 만든 SharePoint 사이트
    ◦ 파일 식별자: 폴더 아이콘을 눌러 인앱웹/데일리.json 선택
    ◦ 파일 콘텐츠: 입력칸을 누르고 식(fx) 탭에서 아래를 붙여넣고 확인
body('Run_daily')?['result']
7.  오른쪽 위 저장 → 테스트 → 수동 → 테스트 로 한 번 실행합니다.
확인: 실행 기록이 초록색 체크면 성공입니다. SharePoint의 인앱웹/데일리.json 을 열어 ginjo-daily-blocks 글자가 들어 있는지 보세요. 빨간 X가 나오면 그 단계를 눌러 오류 메시지를 확인합니다. ("시트 없음"이면 3-1의 확인 항목을 보세요.)
5. 플로우 2 만들기 — 귀책 데이터 저장
플로우 1을 복사하면 빠릅니다.
1.  내 흐름 → 인앱_데일리_읽기 오른쪽 점 세 개 → 사본 저장
2.  이름을 귀책_데일리_읽기 로 바꿉니다.
3.  스크립트 실행 단계에서 파일을 귀책 데일리 엑셀 로, 스크립트를 귀책_데일리_읽기 로 바꿉니다.
4.  파일 업데이트 단계에서 파일을 귀책웹/데일리.json 으로 바꿉니다.
5.  저장 후 수동 테스트합니다.
확인: 귀책웹/데일리.json 에 데이터가 들어갔는지 확인합니다.
6. 플로우 3 만들기 — 화면(HTML) 만들기
이 플로우가 템플릿과 두 데이터를 합쳐 최종 HTML 한 개를 만듭니다.
1.  만들기 → 예약된 클라우드 흐름, 이름 인앱귀책_화면_만들기, 3분마다, 표준 시간대 서울.
2.  SharePoint → 파일 콘텐츠 가져오기 단계 3개를 추가하고 이름을 아래처럼 바꿉니다.
    ◦ Read_template : 인앱귀책웹/인앱귀책웹_템플릿.txt
    ◦ Read_inapp : 인앱웹/데일리.json
    ◦ Read_gwijaek : 귀책웹/데일리.json
3.  (공유 목록을 쓸 경우) SharePoint → 항목 가져오기 2개를 추가합니다.
    ◦ Get_shared_inapp : 목록 인앱 공유, ID 1
    ◦ Get_shared_gwijaek : 목록 귀책 공유, ID 1
4.  SharePoint → 파일 만들기 또는 파일 업데이트 를 추가합니다.
    ◦ 첫 실행은 파일 만들기: 폴더 인앱귀책웹, 파일 이름 인앱귀책 대시보드.html
    ◦ 만들어진 뒤에는 파일 업데이트로 같은 파일을 덮어씁니다.
    ◦ 파일 콘텐츠: 식(fx)에 아래 한 개를 붙여넣습니다.
공유 목록을 쓰는 경우:
replace(replace(base64ToString(body('Read_template')?['$content']), '__INAPP_DAILY_BASE64__', base64(string(union(json(base64ToString(body('Read_inapp')?['$content'])), json(concat('{"sharedInput":', string(body('Get_shared_inapp')), '}')))))), '__GWIJAEK_DAILY_BASE64__', base64(string(union(json(base64ToString(body('Read_gwijaek')?['$content'])), json(concat('{"sharedInput":', string(body('Get_shared_gwijaek')), '}'))))))
공유 목록 없이 먼저 시험하는 경우 (Get_shared 단계 없이):
replace(replace(base64ToString(body('Read_template')?['$content']), '__INAPP_DAILY_BASE64__', base64(string(union(json(base64ToString(body('Read_inapp')?['$content'])), json('{"sharedInput":{"Payload":null}}'))))), '__GWIJAEK_DAILY_BASE64__', base64(string(union(json(base64ToString(body('Read_gwijaek')?['$content'])), json('{"sharedInput":{"Payload":null}}')))))
5.  저장 → 수동 테스트.
확인: 실행이 초록색이면 SharePoint의 인앱귀책웹/인앱귀책 대시보드.html 파일을 다운로드해서 브라우저로 열어 봅니다. 왼쪽에 인앱 / 귀책 두 묶음이 보이고 각각 "내장 데일리 · 운영일 ○○"이 보이면 성공입니다.
자주 나는 오류
• base64ToString 에서 오류: 파일 콘텐츠가 이미 글자로 오는 경우입니다. base64ToString(body('Read_template')?['$content']) 를 string(body('Read_template')) 로 바꿔 보세요. (같은 방식으로 Read_inapp, Read_gwijaek 도)
• union 오류: 데일리.json 이 비어 있거나 {} 인 경우입니다. 플로우 1·2를 먼저 성공시키세요.
• 템플릿 안에 __INAPP_DAILY_BASE64__ 는 한 번만 있어야 합니다. 템플릿을 고칠 때 이 글자를 지우거나 늘리지 마세요.
7. 이슈명단·공유 저장 연결 (선택)
화면의 연결·저장 메뉴에서 "공유 저장" 연결 방법을 안내합니다. 인앱 묶음과 귀책 묶음은 각각 따로 연결해야 합니다. (공유 목록 인앱 공유, 귀책 공유 를 각각 연결)
8. 다음 달 예상(선택, 월말에만 필요)
이번 달 파일에는 다음 달 날짜 시트가 없어서, 월말 며칠은 "시트 없음"으로 비어 보일 수 있습니다. 처음에는 하지 않아도 됩니다.
하려면 플로우를 하나 더 만듭니다. 6시·12시·18시·24시에 4번만 돌립니다.
1.  새 예약 플로우 인앱_다음달예상, 6시간마다 (시작 시각 06:00 서울)
2.  스크립트 실행: 다음 달 인앱 엑셀, 스크립트 인앱_데일리_읽기, 모드 칸에 예상만, 나머지는 -
3.  파일 만들기/업데이트: 인앱웹/다음달예상.json, 내용 body('스크립트 실행')?['result']
4.  플로우 1에 파일 콘텐츠 가져오기(인앱웹/다음달예상.json)를 추가하고, 스크립트 실행의 다음달예상 칸에 base64ToString(body('파일_콘텐츠_가져오기')?['$content']) 를 넣습니다.
5.  귀책도 같은 방식으로 합니다.
이렇게 하면 하루 추가 호출은 인앱 4번, 귀책 4번뿐입니다. (총 약 968번)

10. 이름 바꾼 곳 정리
• 화면 이름: 긴조 → 인앱 / 귀책, 긴급조치 → 인앱전담 / 귀책전담
• 엑셀 시트 이름 앞부분(스크립트 시트머리말): 인앱전담 / 귀책전담 (없으면 예전 "긴급"을 자동으로 찾음)
• SharePoint 폴더: 인앱웹, 귀책웹, 인앱귀책웹
• 템플릿 파일: 인앱귀책웹_템플릿.txt
• 데이터 자리 문구(템플릿 안): __INAPP_DAILY_BASE64__, __GWIJAEK_DAILY_BASE64__
